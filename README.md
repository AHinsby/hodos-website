# HODOS website

Initial website concept for HODOS — a skills and adventure school for families and adults.

## Current state

- Static Danish homepage prototype in `index.html`
- No signup, payment, analytics, or production deployment is configured
- The repository is private

## Local preview

Open `index.html` in a browser, or serve the project with a static web server.

## Project direction

HODOS helps families and adults build practical outdoor skills, sound judgement, and confidence for independent adventures.
